# Контентный сайт на 1С-Битрикс

Сайт на 1С-Битрикс с шаблонами, контентными секциями и пользовательским компонентом голосования.

## Возможности

- Шаблоны страниц, меню и промосекции.
- Пользовательский компонент формы голосования.
- Интеграция PHP-шаблонов с CMS.

## Инженерные акценты

- Разработка и расширение компонентов 1С-Битрикс.
- Работа с CMS-контентом и серверной вёрсткой.
- Организация шаблонов и пользовательских форм.

## Стек

PHP, JavaScript, HTML, CSS.
